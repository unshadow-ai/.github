# Unshadow

### Memory that walks with you.

**Unshadow** is building the memory layer for AI — helping agents and applications remember what matters, understand context, and carry knowledge forward.

We’re working toward AI that doesn't reset every time a conversation ends.

🌐 **[unshadow.dev](https://unshadow.dev)**

---

## What we're building

AI systems are getting better at reasoning, but they still struggle with something fundamental: **memory**.

Unshadow provides infrastructure for persistent, contextual memory that can be used by AI agents, applications, and eventually people themselves.

Our goal is simple:

> **Give AI memory that grows with context, not just conversations.**

### 🧠 Memory

Store meaningful information instead of repeatedly passing entire conversation histories.

### 🔍 Retrieval

Find the right memories when they're needed — using semantic and contextual retrieval.

### 🔗 Relationships

Memories aren't isolated facts. Unshadow can represent how information relates, changes, contradicts, or supersedes other information.

### 🔒 Privacy

We're building toward a memory system where users can retain control over their information, with privacy-first architecture at the core.

### 🧩 Built for AI

Use Unshadow as a memory layer alongside the tools, agents, and frameworks you already use.

## For developers

Unshadow is designed to work alongside your existing AI stack rather than replace it.

```text
Your App / Agent
       │
       ▼
   Unshadow
   ┌───────────────┐
   │   Capture     │
   │   Retrieval   │
   │   Relationships│
   │   Context     │
   └───────────────┘
       │
       ▼
   Your LLM / Agent
```

Whether you're building an AI assistant, autonomous agent, personalized application, or something completely new, memory should be infrastructure — not an afterthought.
